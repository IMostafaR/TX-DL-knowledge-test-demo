# Texas Driver Knowledge Test: Practice Exam (Demo)

A free, self-scoring practice exam for the **Texas Class C driver knowledge test**, built only from the official **Texas Driver Handbook (DPS form DL-7, January 2026)**.

**Live demo:** https://imostafar.github.io/TX-DL-knowledge-test-demo/

> **Disclaimer:** This is an independent study tool. It is **not** an official Texas DPS test, is not affiliated with or endorsed by the Texas Department of Public Safety, and the real exam may word questions differently. Passing this practice exam does not guarantee passing the real test. The official handbook is always the authority: https://www.dps.texas.gov/internetforms/forms/dl-7.pdf

## Features

- **215 multiple-choice questions** (A–D), each with a correct answer, a short explanation and a handbook reference.
- **Mock exam mode:** choose 30, 50, 100 or all 215 questions. Answers are shown at the end, like the real test, with a 70% pass indicator, a score for each topic and a review of every wrong answer.
- **Practice by topic:** instant feedback after each question.
- **My missed questions:** wrong answers are saved in your browser (local storage only) so you can practice them again.
- **Full answer key:** all questions grouped by topic, with explanations and references.
- **Sign and diagram questions** use pictures taken from the handbook.
- Works on phones and desktop, with light and dark themes. No account, no tracking, no server.

## How to use

1. Open the live demo link above.
2. Pick **Mock exam** for a timed-style test, or **Practice by topic** to learn with instant feedback.
3. Review your missed questions and the answer key, then read the matching handbook section.

## Run locally

No build step is needed. Download the repository and open `index.html` in any modern browser.

## Accuracy

Every question, answer and explanation was written from the DL-7 handbook text only. Answer choices are shuffled so the correct letters are spread evenly. If you find an error, please open an issue and include the question and the handbook page that disagrees.

## Data and privacy

Your progress (missed questions) is stored only in your own browser through `localStorage`. Nothing is sent anywhere.
